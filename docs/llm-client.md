# LLM 연결과 호출 한도

제공자·모델이 아직 결정되지 않아 실제 HTTP 어댑터와 LlmClient 빈은 등록하지 않았다. `LlmTransport`를 RestClient로 구현하고 `ValidatingLlmClient(transport, validator, configuredModelVersion)`를 빈으로 연결한다. 모델별 구조화 출력 스키마·응답 추출·키 보관은 그 어댑터에서 처리한다. 요청/응답 원문과 키를 로그로 남기지 않는다.

전체 호출 시간 제한은 Request.timeout을 준수하고 AI 작업 임대 10분보다 짧아야 한다. HTTP 응답을 메모리에 읽기 전 바이트 상한도 설정해야 한다. 공통 계층은 JSON 객체·중복 키·후속 JSON·알 수 없는 필드·Bean Validation을 검증하고 안전한 오류만 전달한다. 원문 인용 여부나 허용 왜곡 유형 같은 의미 검증은 도메인 워커가 수행한다.

`mindlog.ai.max-requests-per-hour`는 사용자당 모든 AI 종류를 합친 시간당 등록 한도다. 운영값 미결정이므로 기본 0은 요청 차단이다. 승인된 값으로 설정하기 전 실제 AI 기능을 활성화하지 않는다. 정시 경계의 고정 시간창 정책은 구현 선택이며 제공자 자체 토큰/전역 요금 한도를 대체하지 않는다.

IdempotencyService의 최초 실행 callback 안에서 quota.consume를 호출한 뒤 JobStore.submit을 실행한다. 같은 트랜잭션이므로 제출 실패는 한도 차감도 롤백하며 같은 키 재전송은 다시 차감하지 않는다. 실제 호출 실패는 등록 한도를 환급하지 않는다. 서버 중단에 따른 작업 재실행은 새 사용자 요청이 아니므로 추가 차감하지 않는다.

V5는 사용자별 현재 시간창 하나만 유지한다. 여러 서버의 동시 예약은 DB 조건부 갱신으로 보호한다. 계정 초기화는 이 행을 지우지 않아 한도 우회를 막고, 탈퇴는 FK CASCADE로 삭제한다. 현재 계정의 소유권·상태 검증과 잠금은 호출 서비스 책임이다. 429에는 다음 시간창까지 남은 초를 Retry-After로 반환한다.
