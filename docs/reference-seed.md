# 확정 마스터 시드와 남은 콘텐츠

V3는 기능명세서 2.5·2.7·2.8·4.1·4.8 및 API 명세서 8절에서 확정된 선택지 3종만 추가합니다.

| 종류 | 활성 수 | 화면별 구분 |
| --- | --- | --- |
| 감정 | 7 | 화남·보통·행복·슬픔·놀람·창피함·스트레스 |
| 상황 | 10 | 온보딩 10, Before 8(팀플·교수님 면담 제외) |
| 증상 | 9 | 온보딩 9, After 8(회피 제외) |

ID·표시 순서는 마스터 조회 API 예시와 맞춥니다. 회피는 behavioral, 기타는 other입니다.
확정된 설명이 없는 증상 description은 NULL입니다.
생성·수정 시각은 카탈로그 개정 시각(2026-09-30 00:00 서울)으로 고정했습니다.
실행 당시 현재 시각을 DB 함수로 생성하지 않습니다.
고정 ID 입력 후 identity 시퀀스를 최댓값에 맞춰 후속 삽입 충돌을 방지합니다.
