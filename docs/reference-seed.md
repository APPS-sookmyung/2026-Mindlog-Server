## 원문과 표시 순서

감정·상황·증상은 V3, 인지왜곡·공통 대처 카드는 V7에서 추가한다. 인지왜곡의 이름·정의·순서는 최종 명세를 따르고, 예시·질문·바꿔보기는 디자인 상세 화면의 문구를 쓴다. ‘마음 읽기’의 일러스트 키는 API 명세에 있는 `distortion-mind-reading`이다. [기능명세서 §6.3](https://app.notion.com/p/f3067858ace1826ea48781fb048bf958) · [가이드 디자인](https://www.figma.com/design/J81yFs4b2ExRxqVAU588IY?node-id=23-14171)

‘파국화’의 정의는 최종 명세의 수정 문구를 적용했다. 디자인의 세 상세 문장이 ‘긍정적 측면 묵살’과 중복되어 2026-11-16에 다음 문구를 확정했다. V8은 해당 유형의 ID와 활성 상태를 보존하면서 세 문장을 반영한다. [파국화 상세 화면](https://www.figma.com/design/J81yFs4b2ExRxqVAU588IY?node-id=23-14426)

- 예시 생각 — 발표에서 한 번 말이 막히면 발표를 전부 망칠 거야.
- 스스로에게 할 질문 — 잠깐 말이 막히면 실제로 어떤 일이 생길 수 있을까요?
- 바꿔보기 — 잠깐 멈추더라도 메모를 보고 다음 문장부터 이어갈 수 있어요.

공통 카드의 제목·태그·설명은 API §8-6과 디자인 화면에서 확인했다. `situation_type_id`는 NULL이다. 고객 기록이나 카드의 표시 상태를 보존하도록 기존 가이드는 이름, 공통 카드는 분류 코드와 제목으로 찾아 갱신한다. 기존 상황별 카드는 DB에 보존하며 공통 카드 API에서는 제외한다. [API 명세서 §8](https://app.notion.com/p/dec67858ace182a3b3d301a6cda55f54) · [대처 카드 디자인](https://www.figma.com/design/J81yFs4b2ExRxqVAU588IY?node-id=23-10973)

빈 DB에서는 V1부터 순서대로 적용한다. 마스터 ID는 이미 적용된 환경에서는 그대로 유지되므로 클라이언트는 조회 응답의 ID를 사용한다. 가입 필드와 기존 데이터 업그레이드는 [DB 적용 절차](database.md)를 참고한다.
