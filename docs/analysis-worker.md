# After 분석 워커

관련 이슈 #58. 계정/Before 서비스 포트와 실제 `LlmClient` 빈이 모두 있을 때만 작업을 실행한다. 테스트 대체 구현은 `src/test`에만 있다.

모델에는 서버의 원문/Before 스냅샷과 활성 왜곡 사전만 전달한다. 원문은 지시가 아닌 데이터로 취급한다. 인용은 원문의 부분 문자열이어야 하며 태그 ID/이름, 패턴 개수, 카드 연결을 검증한다. 패턴 0개와 비어 있는 사전도 정상이며 일반 `돌아보기` 카드를 사용한다. 회복력 태그와 외부요인 Y/N은 결정 전까지 제외한다.

처리 시작, 실패, 결과 반영은 계정 → Before/After → 작업 순서로 잠근다. generation, 소유권, DRAFT, inputVersion, 시도 토큰과 lease를 확인한다. 작업과 피드백 상태를 같은 트랜잭션에 반영하며 중복 실행은 저장 결과를 덮어쓰지 않는다.

모델 식별자는 LLM이 생성한 값이 아니라 `LlmClient.modelVersion()` 설정값이다. `ValidatingLlmClient` 생성 시 세 번째 인자로 실제 모델 식별자를 전달한다. 피드백에 입력 스냅샷과 모델 식별자를 보관하되 공개 폴링 결과에는 포함하지 않는다. 제공자 오류 본문과 원문을 로그/실패 응답에 담지 않는다.

실제 JWT/User/Before 구현과 제공자 HTTP 어댑터 연결, 운영 모델 및 쿼터 설정은 미완료다. 승인된 왜곡 사전 데이터도 아직 비어 있다. `mindlog.ai.dispatch-enabled=false`는 테스트에서 수동 실행과 스케줄러의 경합을 방지한다.
